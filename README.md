# 基于TCP协议的多线程并发聊天室系统的设计与实现

## 一、系统简介

本系统是一个基于TCP协议的多线程并发聊天室系统，支持多种实现方式：

### 版本1：命令行版（Java）
- 使用纯Java Socket实现
- 命令行交互界面
- 适合学习网络编程基础

### 版本2：可视化版（推荐）✨
- 美观的Web界面（仿QQ/微信风格）
- 支持Node.js或Java后端
- 更适合实际使用和论文展示

---

## 🌟 推荐使用：可视化版本

### 最简单方案（推荐Python）
**快速开始（3步运行）：**
1. 检查是否有 Python：运行 `python --version`
2. 安装依赖：`pip install websockets`
3. 启动服务器：`python server.py`
4. 用浏览器打开 index.html

### 备选方案（Node.js）
1. 安装 Node.js：https://nodejs.org/
2. 在代码文件夹执行：`npm install && npm start`
3. 用浏览器打开 index.html

详细说明请查看：`代码/使用说明.md`


## 二、系统功能

### 2.1 核心功能

1. **用户昵称登录**：用户连接服务器后需要输入用户名进行登录，用户名不能重复
2. **公聊消息广播**：用户发送的消息会广播给所有在线用户
3. **私聊消息转发**：用户可以向指定用户发送私聊消息，只有接收者能看到
4. **在线用户列表**：用户可以查询当前所有在线用户
5. **上下线通知**：用户上线或下线时，系统会通知所有在线用户
6. **帮助信息**：提供命令帮助信息

### 2.2 支持的命令

| 命令 | 功能说明 |
|------|---------|
| /users 或 /list | 查看当前在线用户列表 |
| /private <用户> <消息> | 向指定用户发送私聊消息 |
| /p <用户> <消息> | 私聊命令的简写格式 |
| /quit 或 /exit | 退出聊天室 |
| /help 或 /? | 显示帮助信息 |
| 直接输入消息 | 发送公聊消息 |

## 三、系统架构

### 3.1 服务器端架构

服务器端采用多线程并发处理架构：
- **主线程**：监听端口，等待客户端连接
- **线程池**：管理客户端处理线程，提高并发性能
- **用户管理模块**：使用ConcurrentHashMap维护在线用户列表
- **消息处理模块**：处理公聊、私聊、查询等各类消息

### 3.2 客户端架构

客户端采用双线程架构：
- **主线程**：读取用户输入并发送到服务器
- **接收线程**：接收并显示服务器消息

## 四、技术特点

1. **TCP协议通信**：使用Java Socket API实现可靠的TCP连接
2. **多线程并发**：使用线程池处理多个客户端连接
3. **线程安全**：使用ConcurrentHashMap保证用户管理的线程安全
4. **实时通信**：消息即时传递，低延迟
5. **命令式交互**：支持多种命令，操作简便

## 五、环境要求

- Java Development Kit (JDK) 8 或更高版本
- 支持TCP/IP协议的网络环境

## 六、编译和运行

### 6.1 编译程序

打开命令行窗口，进入代码所在目录，执行以下命令：

```bash
cd 代码
javac ChatServer.java
javac ChatClient.java
```

### 6.2 运行服务器端

```bash
java ChatServer
```

服务器启动后会显示：
```
========================================
  基于TCP协议的多线程并发聊天室系统
========================================
服务器启动中...
服务器已启动，监听端口: 8888
等待客户端连接...
```

### 6.3 运行客户端

打开新的命令行窗口，执行：

```bash
java ChatClient
```

客户端会显示欢迎信息和连接状态。

### 6.4 使用示例

1. **启动服务器**：运行`java ChatServer`
2. **启动客户端**：运行`java ChatClient`
3. **输入用户名**：根据提示输入用户名（如：张三）
4. **开始聊天**：
   - 输入消息按回车发送公聊消息
   - 输入`/users`查看在线用户
   - 输入`/private 李四 你好`向李四发送私聊
   - 输入`/quit`退出聊天室

## 九、注意事项

1. 服务器和客户端需要在同一网络中运行，或客户端使用localhost连接本机服务器
2. 默认服务器端口为8888，确保该端口未被占用
3. 用户名不能为空，也不能与已在线用户名重复
4. 退出时请使用`/quit`命令，正常退出
5. 如果连接失败，请检查服务器是否已启动

## 十、常见问题

### Q1: 无法连接到服务器
A: 确保服务器已经启动，并且客户端配置的服务器地址和端口正确。

### Q2: 用户名被占用
A: 该用户名已被其他用户使用，请换一个用户名登录。

### Q3: 消息发送失败
A: 检查网络连接是否正常，或服务器是否正常运行。

### Q4: 如何发送私聊？
A: 使用命令`/private 对方用户名 消息内容`，或简写`/p 对方用户名 消息内容`。
