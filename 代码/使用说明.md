# 可视化聊天室使用说明

## 📁 文件结构

```
代码/
```

## 🚀 快速开始（推荐使用Python！）

### 方案一：Python版本（最简单，推荐！⭐）

#### 1️⃣ 检查是否已安装 Python

在命令行运行：
```bash
python --version
```

如果能看到版本号（如 Python 3.x），说明已安装！如果没有，请去 https://www.python.org/downloads/ 下载安装。

#### 2️⃣ 安装依赖

```bash
cd "c:\Users\11863\Desktop\新建文件夹\网络编程课程设计\代码"
pip install -r requirements.txt
```

或者直接安装：
```bash
pip install websockets
```

#### 3️⃣ 启动服务器

```bash
python server.py
```

看到以下提示就表示成功：
```
========================================
  TCP多线程聊天室 (Python版)
========================================

[启动] 服务器正在启动...
[成功] WebSocket服务器已启动！
[信息] 端口: 8888

按 Ctrl+C 停止服务器
========================================
```

#### 4️⃣ 打开前端

在浏览器中直接打开 `index.html` 文件即可！

### 方案二：Java版本（需要下载库）

如果一定要用Java版本，需要：

#### 1️⃣ 下载 Java-WebSocket 库

- 下载地址：https://github.com/TooTallNate/Java-WebSocket/releases
- 下载文件：`Java-WebSocket-1.x.x.jar` （不要下载javadoc或sources的）

#### 2️⃣ 下载 SQLite JDBC （可选）

- 下载地址：https://github.com/xerial/sqlite-jdbc/releases
- 下载文件：`sqlite-jdbc-3.x.x.x.jar`

#### 3️⃣ 编译运行

```bash
cd "c:\Users\11863\Desktop\新建文件夹\网络编程课程设计\代码"
javac -cp ".;Java-WebSocket-1.x.x.jar;sqlite-jdbc-3.x.x.x.jar" ChatServer.java
java -cp ".;Java-WebSocket-1.x.x.jar;sqlite-jdbc-3.x.x.x.jar" ChatServer
```

## 🎮 使用方法

### 启动多个客户端

1. 打开多个浏览器标签页，都打开 `index.html`
2. 在每个标签页输入不同的用户名（如：张三、李四）
3. 点击「进入聊天室」

### 开始聊天

1. 在左侧用户列表中选择要聊天的用户
2. 在底部输入框输入消息
3. 点击「发送」或按回车键

### 查看聊天记录

- 选择聊天用户后，自动加载历史消息
- 聊天记录会保存到服务器内存中（重启服务器会清空）

## 🐛 常见问题

### Q: 提示「连接失败」？
A: 请确保：
1. 服务器已经启动（运行 `npm start`）
2. 端口8888没有被占用
3. 防火墙没有阻止连接

### Q: 如何停止服务器？
A: 在服务器运行的命令行窗口按 `Ctrl + C`

### Q: 聊天记录会保存吗？
A: 当前版本保存在内存中，重启服务器会清空。如果需要持久化，可以使用数据库。
